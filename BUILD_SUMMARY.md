## 🔧 How to Use

### Open the Website
1. Double-click `index.html` OR
2. Drag into browser window OR
3. Right-click → Open With → Browser

### Quick Customization
1. Open `index.html` with text editor
2. Find & Replace: 1234567890 → YOUR_WHATSAPP_NUMBER
3. Update contact information (address, hours, phone)
4. Save file
5. Refresh browser (Ctrl+F5)

### Deploy to Web
1. Upload all files to hosting provider
2. Maintain folder structure (especially `image folder/`)
3. Point domain to hosting
4. Website is live!

## 🆘 Troubleshooting

### Issue: Images not loading
**Solution:**
- Check `image folder/` exists in same directory
- Verify file names match exactly (case-sensitive)
- Ensure paths use proper folder names

### Issue: WhatsApp links don't work
**Solution:**
- Replace `1234567890` with actual number
- Include country code
- Install WhatsApp on device
- Test on mobile browser

### Issue: Styles not updating
**Solution:**
- Hard refresh: Ctrl+Shift+Delete
- Refresh page: Ctrl+F5
- Close browser completely and reopen
- Check for typos in CSS

### Issue: Mobile menu not working
**Solution:**
- Hard refresh browser
- Check JavaScript console (F12) for errors
- Ensure script.js is in same folder
- Test in different browser
