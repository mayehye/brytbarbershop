📌 IMMEDIATE STEPS (Do These First!)
═══════════════════════════════════════════════════════════════════

1. OPEN THE WEBSITE
   └─ Double-click index.html to open in browser
   └─ Or drag index.html into your browser window

2. CUSTOMIZE WHATSAPP NUMBER
   └─ Open index.html with text editor (Notepad, VS Code, etc.)
   └─ Press Ctrl+H to Find & Replace
   └─ Find: 1234567890
   └─ Replace with: YOUR_WHATSAPP_NUMBER (include country code)
   └─ Click "Replace All"
   └─ Save the file

3. UPDATE BUSINESS INFO
   └─ Find the CONTACT SECTION (around line 280)
   └─ Change: Address, Hours, Phone Number
   └─ Find: FOOTER SECTION (around line 320)
   └─ Update social media links if needed

4. REFRESH BROWSER
   └─ Press Ctrl+F5 (or Cmd+Shift+R on Mac)
   └─ Website should show your updates!

═══════════════════════════════════════════════════════════════════
🎨 COLOR CHANGES (Optional)
═══════════════════════════════════════════════════════════════════

To change from Gold to another color:

1. Open style.css with text editor
2. Find (around line 8): --gold: #d4a24c;
3. Replace with your color code:
   
   Silver:  --gold: #c0c0c0;
   Green:   --gold: #2ecc71;
   Purple:  --gold: #9b59b6;
   Red:     --gold: #e74c3c;
   Blue:    --gold: #3498db;

4. Also change: --gold-hover to lighter version of same color
5. Save & refresh browser (Ctrl+F5)

🆘 QUICK TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

Images not showing?
→ Check folder/image names match exactly
→ Use proper path: image folder/PROFILE/name.jpg

WhatsApp links not working?
→ Replace 1234567890 with REAL WhatsApp number
→ Include country code (+233, +1, etc.)

Menu not working on mobile?
→ Hard refresh: Ctrl+Shift+Delete
→ Check browser console (F12)

Website looks different?
→ Clear cache: Ctrl+Shift+Delete
→ Refresh page: Ctrl+F5
