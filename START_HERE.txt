🔧 TROUBLESHOOTING

Q: Images not loading?
A: Make sure "image folder" folder is in same directory as index.html

Q: WhatsApp links not working?
A: Replace 1234567890 with actual WhatsApp number (include country code)

Q: Changes not showing?
A: Hard refresh: Press Ctrl+Shift+Delete to clear cache, then Ctrl+F5

Q: Menu not working on mobile?
A: Clear cache and refresh. Check if JavaScript is enabled.
